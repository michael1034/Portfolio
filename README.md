# My First Portfolio

This is my personal portfolio website that I created as a first-year BS Computer Science student. It contains information about me, my skills, and some of the projects that I have made while learning programming and web development.

## About the Project

The purpose of this project is to practice the basics of front-end web development and create a website where I can show my skills and projects.

The portfolio includes:
- Information about me
- My programming and web development skills
- My projects
- Navigation links
- Interactive buttons

## Technologies Used

- HTML
- CSS
- JavaScript

## How I Built It

I used HTML to create the structure of the website, including the header, sections, navigation bar, and footer.

I used CSS to design the website. I used Flexbox for the navigation bar and profile layout, CSS Grid for displaying my skills, custom color variables for managing colors, and transform effects for button hover animations.

I used JavaScript to add interactivity to the website, such as showing and hiding my projects when the "View My Projects" button is clicked.

## What I Learned

While making this portfolio, I learned more about:
- HTML structure and semantic elements
- CSS Flexbox
- CSS Grid
- CSS variables
- Hover effects and transforms
- Basic JavaScript and DOM manipulation
- Organizing HTML, CSS, and JavaScript into separate files
